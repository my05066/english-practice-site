# Audio files

VoiceStudio audio has not been generated yet. Add MP3s here using these filenames.

- `phonemes/<symbol>.mp3` uses the literal IPA symbol, for example `phonemes/θ.mp3` or `phonemes/iː.mp3`. When a clip cannot play, the browser attempts to read the example word aloud.
- `topics/topic-<id>.mp3` holds the complete Week 1 model answer, for example `topics/topic-1.mp3`.
- `topics/topic-<id>-<sentence>.mp3` holds one model answer sentence, for example `topics/topic-1-2.mp3` for the second sentence of Topic 1. IDs and sentence numbers start at 1.

Each VoiceStudio slot displays **音频还没生成** when its file is unavailable.
